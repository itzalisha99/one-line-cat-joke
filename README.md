A make.fun bounty entry. The program writes one cat joke — a single line under 200 characters — to `/output/entry.txt`.

## The joke

> The vet said my cat is overweight. My cat said the vet is underfed.

The vet delivers the diagnosis; the cat returns the verdict. A clean reversal, no pun, no box, no laser pointer.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

The entry is checked by a self-authored `validate()` gate that mirrors the bounty gate: UTF-8 text, 1 to 200 characters, not only whitespace, exactly one line.
